# Scorpion シミュレーションモデル

Fusion の保存済み `scorpion v13` を基に、17リンクと16回転ジョイントを出力しています。修正後の `joint6_R/L` と `joint7_R/L` を含み、名前に `_miss` を含む旧ボディはモデルやメッシュに含めていません。 上部横パイプは 300 mm で、左右の肩の回転中心間は 329.816 mm です。

## フォルダー

- `urdf/`: 汎用 URDF、ROS 2 用 URDF、SRDF、メッシュ、ROS 2 パッケージ。
- `mujoco/`: MuJoCo の MJCF と実行用 Python。
- `genesis/`: Genesis 用 URDF、メッシュと実行用 Python。
- `isaac_sim/`: Isaac Sim 向け USD と実行用 Python。
- `gazebo_jetty/`: Gazebo Sim 向け SDF モデル、ワールドと起動スクリプト。
- `source/`: Fusion からの抽出結果、リンク・ジョイント情報、衝突設定と検証結果。

各フォルダーの README に起動方法があります。`initial_state.json` は Fusion で表示していた姿勢を記録しています。MJCF には `neutral` と `fusion_current` の2種類のキーフレーム、USD には中立姿勢と現在姿勢のステージがあります。

## 衝突・位置合わせ

外部物体との衝突と、直接接続されていないリンク同士の自己衝突を想定した形状を用意しました。隣接する親子リンクの衝突は、関節の接続部が接触しているため除外しています。URDF の汎用ビューアーが SRDF を自動的に適用するとは限りません。使用先で自己衝突を有効にし、`collision_config.json` と `scorpion.srdf` の除外設定を適用してください。衝突メッシュは元形状を凸形状の集合で近似しており、精密な干渉解析の代わりにはなりません。

Fusion 上で左右の肩と腕の位置、既存ジョイントの回転中心・軸、右腕部品のリンク内位置を照合しました。測定結果は `source/alignment_check.json` にあります。一方、Fusion の実体同士の交差計算では、`joint6_R/L` と同じリンク内のケースで約115.6 mm³、`joint7_R/L` と同じリンク内のケースで約305.3 mm³の重なりが残っています。詳細は `source/cad_overlaps.json` を参照してください。同一リンク内の重なりは通常の剛体自己衝突では検出されないため、実物の組み付け確認やCADでの干渉修正とは別です。

## 質量とジョイント値

フレームの `base` と `body`、モーター関連のボディは Fusion に設定されていた密度 7850 kg/m³ を使用しました。それ以外の造形部品は中実 PLA、密度 1240 kg/m³ と仮定して、ボディごとの体積・重心・慣性からリンク単位に合成しています。この仮定での全質量は約 15.74 kg です。実際のインフィル率、モーター実測質量、ネジなどは反映していません。質量と慣性は実測値に置き換えてください。

各ジョイントの可動限界は未測定です。URDFでは連続回転として出力し、トルク 1 N·m、速度 2 rad/s、駆動ゲインは仮値です。実機に使う前に正しい値を設定してください。シミュレーションが動くことは実機での安全な動作を保証しません。

## 検証した範囲

MuJoCo では 16 軸を読み込み、中立姿勢と Fusion 保存姿勢の順運動学と接触を確認しました。URDF と SDF はジョイントとメッシュ参照を照合し、USD は OpenUSD で各ステージを検査しました。検証範囲はモデル構造と静的な姿勢計算です。検証内容の詳細は `source/validation.json` にあります。

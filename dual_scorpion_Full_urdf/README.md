# Scorpion シミュレーションモデル

Fusion の保存済み `scorpion v11` を基に、17リンクと16回転ジョイントを出力しています。修正後の `joint6_R/L` と `joint7_R/L` を含み、名前に `_miss` を含む旧ボディはモデルやメッシュに含めていません。

## フォルダー

- `urdf/`: 汎用 URDF、ROS 2 用 URDF、SRDF、メッシュ、ROS 2 パッケージ。
- `mujoco/`: MuJoCo の MJCF と実行用 Python。
- `genesis/`: Genesis 用 URDF、メッシュと実行用 Python。
- `isaac_sim/`: Isaac Sim 向け USD と実行用 Python。
- `gazebo_jetty/`: Gazebo Sim 向け SDF モデル、ワールドと起動スクリプト。
- `source/`: Fusion からの抽出結果、リンク・ジョイント情報、衝突設定と検証結果。

各フォルダーの README に起動方法があります。`initial_state.json` は Fusion で表示していた姿勢を記録しています。MJCF には `neutral` と `fusion_current` の2種類のキーフレーム、USD には中立姿勢と現在姿勢のステージがあります。

## 衝突・位置合わせ

外部物体との衝突と、直接接続されていないリンク同士の自己衝突を想定した形状を用意しました。隣接する親子リンクの衝突は、関節の接続部が接触しているため除外しています。URDF の汎用ビューアーが SRDF を自動的に適用するとは限りません。使用先で自己衝突を有効にし、`collision_config.json` と `scorpion.srdf` の除外設定を適用してください。衝突メッシュは元形状を凸形状の集合で近似しており、精密な干渉解析の代わりにはなりません。

4つの修正部品の取り付け穴は、各旧部品の対応する穴位置に合わせてあります。Fusion 上で再照合した値は `source/alignment_check.json` にあります。一方、Fusion の実体同士の交差計算では、`joint6_R/L` と同じリンク内のケースで約115.6 mm³、`joint7_R/L` と同じリンク内のケースで約305.3 mm³の重なりが残っています。詳細は `source/cad_overlaps.json` を参照してください。同一リンク内の重なりは通常の剛体自己衝突では検出されないため、実物の組み付け確認やCADでの干渉修正とは別です。

## 質量とジョイント値

フレームの `base` と `body`、モーター関連のボディは Fusion に設定されていた密度 7850 kg/m³ を使用しました。それ以外の造形部品は中実 PLA、密度 1240 kg/m³ と仮定して、ボディごとの体積・重心・慣性からリンク単位に合成しています。この仮定での全質量は約 16.09 kg です。実際のインフィル率、モーター実測質量、ネジなどは反映していません。質量と慣性は実測値に置き換えてください。

各ジョイントの可動限界は未測定です。URDFでは連続回転として出力し、トルク 1 N·m、速度 2 rad/s、駆動ゲインは仮値です。実機に使う前に正しい値を設定してください。シミュレーションが動くことは実機での安全な動作を保証しません。

## 検証した範囲

MuJoCo 3.16.0 で16軸の読み込み、Fusion表示姿勢と34姿勢の位置計算、1000ステップ、17リンクすべての衝突プローブを確認しました。姿勢は中立姿勢、Fusion表示姿勢、および各ジョイント単独の ±5° で、全可動域の干渉確認ではありません。Genesis 1.4.4 は CPU・ヘッドレスで50ステップを確認しました。

USD は OpenUSD でリンク・ジョイント・メッシュを検査し、Gazebo の SDF は XML 構造とメッシュ参照を検査しました。Isaac Sim / PhysX と Gazebo Sim での実行は未検証です。検証内容の詳細は `source/validation.json` にあります。
